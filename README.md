# 超级IP智能体 · GitHub Pages

这是手机网页的静态展示版。`content.json` 是发布时的内容快照；图片在 `assets/` 中。视频或二维码如果存储在原站，静态版会继续读取原站的媒体地址。

GitHub Pages 不提供服务器、数据库或上传接口。内容管理和上传仍在原站进行：<https://super-ip-ai-showcase-1113.elated-cat-5292.chatgpt.site/admin>。原站保存新内容后，静态版需要重新更新 `content.json` 并发布。

网页中的收款入口只有在配置了真实收款链接或二维码后才可使用。支付结果需以收款平台记录为准。
